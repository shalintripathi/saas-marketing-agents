# Roadmap

**North Star:** be the most trusted, always-current open-source *AI marketing team for B2B SaaS* — the default place a marketer goes for an agent, skill, or workflow — kept honest by staying current with how AI search (SEO/AEO/GEO) and agentic marketing actually work.

This project is **actively maintained**. Shipped work is in the [CHANGELOG](CHANGELOG.md); what's below is what's planned. Ideas and votes welcome via [issues](https://github.com/shalintripathi/saas-marketing-agents/issues).

## Now (in progress)

- Keep the [AEO/GEO Playbook](guides/aeo-geo-playbook.md) current as Google/Bing and the answer engines change.
- Grow the [marketing loops](loops/README.md) library (recurring-cadence, agent-run workflows).
- Distribution: get listed on the relevant awesome-lists and Claude plugin directories.

## Next

- **`brand-context.md` / ICP config** every agent reads first, so output is tailored to *your* product, ICP, and voice instead of generic B2B.
- **Native subagents** — expose the 77 personas as first-class Claude Code subagents (`@content-copywriter`), not just skill-referenced files.
- **More marketing loops** — quarterly launch loop (weekly content engine, weekly competitive intel, and monthly ABM have shipped).
- **Per-agent examples** — a golden input/output example per agent, which also improves trust and AI-citation quality.
- **`vibe`-friendly install** — verify and document install across Cursor, Copilot, Aider, Windsurf from one source of truth.

## Later

- **GitHub Pages catalog** — a browsable, copy-to-clipboard site for all 77 agents.
- **MCP tool recipes** — connect analytics/SEO/CRM tools (GA4, GSC, HubSpot, Ahrefs) so agents move from advisory to executable.
- **Evaluation harness** — rubrics and regression checks for agent output quality.
- **De-duplicate agent sources** — single source of truth for each persona, with the browseable and installable copies generated from it.

## Principles

- **Freshness over volume.** We would rather ship one genuinely current guide than ten stale personas.
- **Honesty over hype.** Effect sizes are cited; contested claims are flagged; we don't invent metrics.
- **Useful first.** Stars follow usefulness, not the other way around.
